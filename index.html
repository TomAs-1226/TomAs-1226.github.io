◆ CS & IT Conference Proceedings · Vol 16

Ornimetrics: Design and Evaluation of an AI-Enabled Smart Bird Feeder for Species Recognition, Waste Reduction, and Ecological Monitoring

Baichen Yu, Tyler Boulom — Woodbury University

A peer-reviewed study of an embedded-camera feeder using YOLOv11 recognition to identify species, manage food distribution, and log behavioural data — reporting detection performance and species-level waste analysis.

⬡ Model release · ornimetrics-edge

The edge model, public on Hugging Face

backbone EfficientNetV2-S, shared multi-head pipeline
detect YOLOv11n — bird / squirrel / person / dog
classify 555 (NABirds) + 302 (iNaturalist)
welfare Mahalanobis anomaly screen
re-id ArcFace individual tracking
Robotics · Open-source library

FRC Catalyst

A Java library for FIRST Robotics Competition teams. Competition-ready mechanisms in a few builder calls — what used to take ~150 lines now takes about 8.

150→8lines of boilerplate
7mechanism builders
3drivetrain subsystems

Built on Phoenix 6 + WPILib 2026. Every mechanism ships with Motion Magic, gravity feedforward, simulation, telemetry, health monitoring, live tuning and SysId — automatically. Ships with browser-based tuning & docs tools.

LinearMechanismRotationalMechanism FlywheelMechanismRollerMechanism WinchMechanismClawMechanism PneumaticMechanismSwerveSubsystem VisionSubsystemLEDSubsystem
Elevator.java FRC Catalyst
// a full competition elevator — Motion Magic,
// feedforward, sim, telemetry, tuning included
var elevator = LinearMechanism.builder()
    .motors(9, 10)
    .gearing(12.0)
    .drumRadius(0.022)
    .softLimits(0, 1.5)
    .motionMagic(3.0, 6.0)
    .gravityFF(0.35)
    .build();

elevator.goTo(1.2); // metres. done.
